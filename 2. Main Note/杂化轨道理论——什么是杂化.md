## 1.1 对于4个单键——Carbon的杂化轨道

上一节我们知道了电子轨道的基本概率区域形状，那么什么是杂化轨道，我的理解是，不同轨道概率区域重叠之后形成的全新的概率区域轨道（这个新的概率区域轨道表征为化合物的形状），我们先来看6个原子的Carbon：

![[Pasted image 20250803165246.png]]

可以看到电子再碳原子周围的分布，其中2p轨道中只有2对杂化轨道有电子，C基本不会已单质形式存在，而是会经常和4个原子单质进行结合形成化合物，说明C拥有4个能量相同的价电子。

当三个2p轨道（含2电子）和一个2s轨道（含两电子）进行杂化后，便会形成4个单电子的杂化轨道，每一个轨道记作 $2sp^{3}$ ，其中2代表杂化轨道所在能层（注意这些杂化轨道能量介于2p和2s之间），s继承自杂化前的2s轨道，p继承自杂化前的2p轨道，上角标3说明3个2p轨道进行了杂化。

![[Pasted image 20250803165932.png]]

下面第一张图展示了，杂化前的2p与2s的重叠位置关系，两者能量混合，杂化后，便是下面图2的状态

![[Pasted image 20250803170558.png]]

![[Pasted image 20250803170631.png]]

对于绿色的每一个 $2p^{3}$ 杂化轨道，它们都只含有一个电子。由于这4个共价键能量相同，所以在三维空间中均匀排列形成了正四面体的状态，每个键角都相等（约为109.5°）。

## 1.3 双键——乙烯

那么杂化轨道理论如何解释乙烯分子中的C=C双键呢：

![[Pasted image 20250803171807.png]]

上面我们提到，为了与4个原子进行成键，C原子杂化形成了4个轨道，而对于乙烯 $H_{2}C=CH_{2}$ ，每个C则只有3个杂化轨道，也就是1个2s（2个电子）轨道只和2个2p（1个电子）轨道进行杂化形成3个杂化轨道 $2sp^{2}$ ，其中C的3个杂化轨道中有2个与H原子形成 $\sigma$ 键，剩下的1个杂化轨道和另一个C原子剩下的1个杂化轨道形成C与C的 $\sigma$ 键：

## 1.4 其他轨道

对于乙炔，也就是CC三键呢？与上面同理，1个2s（2个电子）和1个2p（0电子）形成2个杂化轨道 $2sp$ ，而剩下两个未杂化的2p形成 $\pi$ 键，两个 $\pi$ 键相互垂直（主要是因为2p键相互垂直）

对于NH3，由于N比C多一个电子，所以3个2p轨道均填充了1个电子，1个2s（2个电子）与3个2p（3个电子）杂化形成4个杂化轨道，但是其中一个杂化轨道有两个电子，形成孤电子对不与其他原子成键。
